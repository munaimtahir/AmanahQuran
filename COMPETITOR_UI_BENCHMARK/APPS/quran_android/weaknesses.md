# Quran for Android — UX Weaknesses & Anti-Patterns to Avoid

- **Network Dependency on First Run**: Not truly offline out-of-the-box. Requires immediate asset download.
- **No Bundled Offline Search**: Search completely fails without downloading external SQLite translation files.
- **No IndoPak Script Bundled**: Madani Uthmani is default; IndoPak requires navigating download managers.
- **Audio Bar Dominates Chrome**: Audio player occupies half the revealed chrome space, adding clutter for silent readers.
