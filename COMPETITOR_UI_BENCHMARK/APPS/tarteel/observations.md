# Tarteel: AI Quran Memorization — UX & Surface Observations

1. **Cutting-Edge Voice Interactivity**: AI model listens to speech and automatically scrolls/highlights the corresponding verse.
2. **Extensive Habit Gamification**: Features daily streaks, calendar heatmaps, reading streak freezes, and target verse goals.
3. **Commercial Freemium Friction**: Core AI memorization features and unlimited recitation sessions are locked behind expensive subscriptions ($9.99/mo, $69.99/yr).
4. **Mandatory Account Gate**: Pushes user to create an account via Google/Apple/email immediately upon onboarding.
5. **Modern Design Language**: Highly polished Material 3 design, smooth fluid animations, and crisp modern typography.
