# The Glorious Quran — UX Weaknesses & Anti-Patterns to Avoid

- **Visual Density**: Displaying Arabic, Urdu, and English concurrently creates high vertical scrolling distance per ayah.
- **Flat Bookmark Organization**: Lacks tagging, folders, or color-coding for extensive study bookmarks.
- **Search Flexibility**: Search does not easily handle transliterations or diacritic-agnostic Arabic queries.
- **Legacy UI Components**: Some older dialogs and button styles lack modern Jetpack Compose fluid physics.
