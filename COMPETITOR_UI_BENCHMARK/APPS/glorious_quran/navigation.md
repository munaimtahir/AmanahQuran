# The Glorious Quran — Information Architecture & Navigation Map

- **Home Surface**: Fast entry buttons (Read Quran, Translations, Search, Bookmarks, Audio Recitation).
- **Quran Navigation**: Tabbed Surah Index (114 Surahs with revelation markers), Juz Index (30 Paras), Page Index.
- **Reader Modes**:
  - *Verse-by-Verse Bilingual View*: Arabic text displayed in clear header followed by Urdu (Irfan-ul-Quran) and English (The Manifest Quran).
  - *Arabic-Only Mushaf View*: Standard reading mode for tilawat.
  - *Translation-Only Mode*: Continuous reading of theological translation without Arabic glyphs.
- **Settings Sheet**: Font size controllers, script selection, auto-scroll velocity slider, and theme switcher.
