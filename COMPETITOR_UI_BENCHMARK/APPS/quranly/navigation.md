# Quran by Quranly — Information Architecture & Navigation Map

- **Bottom Navigation**: Home / Habit Dashboard, Quran Reader, Habits & Challenges, Profile & Settings.
- **Home Surface**: Prominent Streak Counter (e.g. "5 Day Streak"), Daily Quran Goal Progress Ring, Habit Freeze status, Reflection card, Start Session CTA.
- **Reading Session Flow**: Guided card-based reader (e.g. "Read 5 verses today"), celebratory completion modal, streak update animation.
- **Challenge Arena**: Community habit challenges, milestone badges, and reading routines.
