# Al Quran (Tafsir & by Word) — Information Architecture & Navigation Map

- **Home Surface**: Search bar, Daily Ayah widget, Last Read card, Quick Links (Surah, Juz, Page, Bookmarks, Planner, Library).
- **Navigation Drawer / Tabs**: Surah Index, Juz Index, Revelation Order Index, Page Index, Bookmarks / Pins, Settings.
- **Reader Modes**:
  - *Translation Mode*: Continuous vertical scroll of ayah cards with inline word breakdown.
  - *Mushaf Mode*: Classical 15-line page view.
  - *Tafsir Mode*: Sliding bottom sheet or full-screen view for commentary.
- **Settings Hierarchy**: Nested categorized settings (General, Audio, Reading, Themes, Translation, Backup & Restore).
