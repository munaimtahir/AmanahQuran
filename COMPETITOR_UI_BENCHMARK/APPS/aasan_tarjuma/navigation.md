# Aasan Tarjuma-e-Quran — Information Architecture & Navigation Map

- **Home Surface**: Clean portal with Surah List, Para (Juz) List, Ruku Index, Bookmarks, and Last Read resume button.
- **Navigation**: Traditional South Asian Quranic divisions (Surah, Para, Ruku, Manzil).
- **Reader Surface**:
  - High-resolution IndoPak Arabic script with interlinear / block Urdu translation.
  - Footnote / Commentary expandable drawer for brief theological explanations (Hashiya).
  - Auto-scroll toolbar with variable speed control.
- **Settings**: Font sizing for Arabic, font sizing for Urdu, day/night/sepia themes, screen keep-awake toggle.
