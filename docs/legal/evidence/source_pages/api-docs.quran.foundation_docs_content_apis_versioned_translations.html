Translations​

Get list of available translations. Use language query to get translated names of authors in specific language(e.g language=ur will send translation names in Urdu).

For list of available language see /resources/languages endpoint.

Query Parameters
    language string

    ISO language code to return translated names in that language when available; defaults to English otherwise.

  • 400
