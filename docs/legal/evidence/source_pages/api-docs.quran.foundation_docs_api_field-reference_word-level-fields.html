📙 Translation Fields (translation_fields)​

These fields can be used in the translation_fields query parameter:

FieldDescription
chapter_idChapter number of this verse
verse_numberVerse number within the chapter
verse_keyVerse key (e.g., 2:255)
juz_numberJuz number this verse belongs to
hizb_numberHizb number this verse belongs to
rub_el_hizb_numberRub el Hizb number for the verse
page_numberMushaf page number
ruku_numberRuku number this verse belongs to
manzil_numberManzil number this verse belongs to
resource_nameName of the translation resource
language_nameName of the translation language
language_idLanguage ID
idID of the translation

📕 Tafsir Fields (tafsir_fields)​

These fields can be used in the tafsir_fields query parameter:

FieldDescription
chapter_idChapter number of this verse
verse_numberVerse number within the chapter
verse_keyVerse key (e.g., 2:255)
juz_numberJuz number this verse belongs to
hizb_numberHizb number this verse belongs to
rub_el_hizb_numberRub el Hizb number for the verse
page_numberMushaf page number
group_verse_key_fromGrouped tafsir start verse key
group_verse_key_toGrouped tafsir end verse key
group_tafsir_idGroup tafsir ID
start_verse_idStart verse ID
end_verse_idEnd verse ID
resource_nameName of the tafsir resource
language_nameName of the tafsir language
language_idLanguage ID
idID of the tafsir
